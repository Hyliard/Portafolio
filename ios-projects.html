ContractorHoursPay

Aplicación nativa conectada a API

App para contratistas que registran horas y cobran por hora. Gestiona clientes, contratos con tarifa normal y de horas extra, registros de trabajo, facturas y pagos, con un resumen mensual de lo generado, cobrado, pendiente y vencido. Consume mi Auth API con URLSession, sin librerías externas: registro, inicio de sesión, cambio de contraseña, eliminación de cuenta, gestión de dispositivos y avatar. Arquitectura MVVM con servicios por recurso, entornos configurables con xcconfig (local, Raspberry Pi y Tailscale) y herramientas de desarrollo con inspector de red y logs sanitizados.

  • SwiftUI
  • MVVM
  • URLSession
  • API REST

PassGenerator iOS

Aplicación nativa

Aplicación nativa con SwiftUI y NavigationStack. Genera contraseñas con aleatoriedad segura, indicador de fortaleza y una interfaz accesible en modo claro y oscuro. Usa SecRandomCopyBytes y muestreo con rechazo para evitar sesgo. Garantiza caracteres de cada categoría seleccionada y confirma el copiado al portapapeles de forma accesible.

  • SwiftUI
  • NavigationStack
  • SecRandomCopyBytes
